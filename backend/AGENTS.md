# Backend

FastAPI app managed with uv (`pyproject.toml`). Run in Docker via the root `Dockerfile`.

- `main.py` - app; `GET /api/hello`; serves `static/` at `/` (mounted last)
- `auth.py` - fake login: `POST /api/login` (user/password) sets an HMAC-signed httpOnly `session` cookie; `POST /api/logout`; `GET /api/me`; `current_user` dependency for protected routes. Secret from `PM_SECRET` (dev default)
- `db.py` - sqlite3 access: schema creation, `ensure_board` (creates and seeds a user's board), `fetch_board`, and card/column mutations. DB path from `PM_DB_PATH` (default `pm.db`). Unknown or foreign ids raise `LookupError`, mapped to 404 in `main.py`
- `board.py` - routes (titles are trimmed, 1-200 characters; details up to 5000; the DB connection dependency has `scope="function"` so changes are committed before the response is sent), all scoped to the signed-in user: `GET /api/board`, `PUT /api/columns/{id}`, `POST /api/cards`, `PUT|DELETE /api/cards/{id}`, `POST /api/cards/{id}/move` (`column_id`, `position`). Ids are `col-N` / `card-N`. Create returns the card (201); the others return the full board
- `ai.py` - `POST /api/chat` (`message`, `history` of `{role, content}`). Builds a system prompt containing the user's current board JSON, calls OpenRouter (OpenAI SDK, `openai/gpt-oss-120b`, key from `OPENROUTER_API_KEY`) with Structured Outputs (`AIResponse`: `reply` and a list of `operations`: create_card, edit_card, move_card, delete_card, rename_column; empty list means no change). Operations are applied through the `db.py` functions; invalid ones are skipped and listed in the reply. Returns `{reply, board}` where `board` is the fresh board if anything changed, else null. Model or parse failures (including a missing key) return 502; the client has a 60 second timeout; a request may carry at most 20 history messages. Operations with a blank title are skipped like other invalid ones. Live tests in `tests/test_ai.py` are skipped without the key; run them with `uv run --env-file ../.env pytest`
- `static/` - empty in git; the Dockerfile copies the built frontend (`frontend/out`) here
- `tests/` - pytest (`conftest.py` gives a temp DB and logged-in `client` / `other_client`); run with `uv run pytest` from this directory
