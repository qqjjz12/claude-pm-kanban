# Backend

FastAPI app managed with uv (`pyproject.toml`). Run in Docker via the root `Dockerfile`.

- `main.py` - app; `GET /api/hello`; serves `static/` at `/` (mounted last)
- `auth.py` - accounts: `POST /api/register` (username 3-32 of `A-Za-z0-9_.-`, password 8-200, unique ignoring case), `POST /api/login`, `POST /api/logout`, `GET /api/me`, `POST /api/me/password` (current + new), `POST /api/me/delete` (password confirm; cascades boards). Passwords are scrypt-hashed in `users.password_hash`. A successful login/register sets an HMAC-signed httpOnly `session` cookie (secret `PM_SECRET`, dev default). `current_user` also requires the user to still exist. The demo account `user` / `password` is created at startup
- `db.py` - sqlite3 access: schema creation, users (`create_user` seeds a sample board), boards (`create_board` with templates `standard` / `sample` / `empty`, `ensure_board(conn, username, board_id=None)` for ownership checks), `migrate` of pre-account databases, `fetch_board`, and card/column mutations. DB path from `PM_DB_PATH` (default `pm.db`). Unknown or foreign ids raise `LookupError`, mapped to 404 in `main.py`
- `board.py` - routes (titles are trimmed, 1-200 characters; details up to 5000; the DB connection dependency has `scope="function"` so changes are committed before the response is sent), all scoped to the signed-in user. Board-level routes take an optional `?board=<id>` query (default: the user's first board; another user's board is 404): `GET /api/board`, `POST /api/columns`, `DELETE /api/columns/{id}`, `POST /api/columns/{id}/move` (`position`), `PUT /api/columns/{id}`, `POST /api/cards`, `PUT|DELETE /api/cards/{id}`, `POST /api/cards/{id}/move` (`column_id`, `position`). Boards CRUD (not scoped by `?board`): `GET|POST /api/boards` (`name`, `template`), `PUT|DELETE /api/boards/{id}` (the last board cannot be deleted: 409). Cards have `priority` (`none|low|medium|high`), `dueDate` (`YYYY-MM-DD` or null; sent as `due_date`, `""` clears) and `labels` (up to 10 strings of 1-30 characters, trimmed, deduplicated ignoring case). On `PUT /api/cards/{id}` omitted fields keep their value. Card details (board-scoped): `GET /api/cards/{id}/detail`, `POST /api/cards/{id}/comments` (`body`, 1-2000), `DELETE /api/comments/{id}`, `POST /api/cards/{id}/checklist` (`text`), `PUT /api/checklist/{id}` (`text` and/or `done`), `DELETE /api/checklist/{id}`; each returns `{comments, checklist}` for the card. Board cards also carry `commentCount` and `checklist: {done, total}`. Ids are `col-N` / `card-N`. Create returns the card (201); the others return the full board
- `ai.py` - `POST /api/chat` (`message`, `history` of `{role, content}`). Builds a system prompt containing the user's current board JSON, calls OpenRouter (OpenAI SDK, `openai/gpt-oss-120b`, key from `OPENROUTER_API_KEY`) with Structured Outputs (`AIResponse`: `reply` and a list of `operations`: create_card, edit_card (both accept optional priority, due_date, labels), move_card, delete_card, rename_column, create_column, delete_column, move_column; empty list means no change). Operations are applied through the `db.py` functions; invalid ones are skipped and listed in the reply. Returns `{reply, board}` where `board` is the fresh board if anything changed, else null. Model or parse failures (including a missing key) return 502; the client has a 60 second timeout; a request may carry at most 20 history messages. Operations with a blank title are skipped like other invalid ones. Live tests in `tests/test_ai.py` are skipped without the key; run them with `uv run --env-file ../.env pytest`
- `static/` - empty in git; the Dockerfile copies the built frontend (`frontend/out`) here
- `tests/` - pytest (`conftest.py` gives a temp DB and logged-in `client` / `other_client`); run with `uv run pytest` from this directory
